01

C++ · 로컬 AI 연동

ezTrans DLL 번역 브리지

아랄트랜스 플러그인의 호출 방식을 분석하고, Ollama 번역을 사용할 수 있는 C++ DLL을 만들었습니다.

DLL 구현 · 품질 개선 중

해결하려던 문제

로컬 AI로 게임 대사를 번역하려 했지만, 기존 플러그인의 호출 방법을 알 수 없었습니다. 번역을 기다리는 시간과 반복 요청도 줄여야 했습니다.

맡은 작업

Visual Studio 개발 도구로 export 목록을 확인하고, Ghidra에서 함수 포인터로 번역을 호출하는 흐름을 찾았습니다. 기존 ordinal을 유지한 ezTransXP.dll을 만들어 Ollama와 연결했습니다.

구현한 내용

같은 문장은 캐시에서 불러오고, 미완료 작업은 저장했다가 다음 실행에 이어서 처리하도록 했습니다. 숫자·기호와 이름만 있는 입력을 구분해 대사를 먼저 처리했습니다.

기술 문제와 개선 내용
  • 호출 방식 확인export 목록과 디컴파일 결과에서 플러그인의 진입점과 간접 호출 구조를 확인했습니다. 이를 바탕으로 기존 ordinal을 유지한 대체 DLL을 만들었습니다.
  • 중복 번역과 대기 시간 처리같은 원문은 저장된 AI 번역을 재사용하고 중복 요청을 줄였습니다. 처리하지 못한 작업은 파일에 남겨 다음 실행 때 이어서 처리합니다.
  • 번역이 필요한 입력 구분숫자·기호와 이름만 들어온 입력을 구분했습니다. 이름 목록과 정확히 일치하는지 확인해 대사 전체가 제외되는 일을 줄이도록 했습니다.
  • 번역 오류 수정문맥과 관계 설정을 별도 파일로 관리했습니다. 실제 사용 중 발견한 글자 깨짐, 프롬프트 노출, 문장 잘림을 확인하고 수정했습니다.
  • 추가한 규칙 재검토문장 연결과 호칭 보정 규칙을 추가한 뒤 새 번역에서 오역이 늘어났습니다. 이후에는 규칙을 추가할 때 원문과 결과를 비교하며 확인했습니다.
