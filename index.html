ezTrans DLL 번역 브리지

아랄트랜스의 기존 플러그인 인터페이스를 분석하고,
로컬 AI 번역을 연결하는 C++ 대체 DLL을 만들었습니다.

DLL 구현 · 품질 개선 중

시작한 문제

기존 번역기는 대사 문맥과 이름을 일관되게 처리하는 데 한계가 있었습니다. 로컬 AI를 연결하려면 호출 규약을 알기 어려운 플러그인 구조와 긴 번역 대기 시간을 함께 다뤄야 했습니다.

접근과 구현

Visual Studio 개발 도구로 export 목록을 확인하고 Ghidra로 호출 흐름을 추적했습니다. 번역 로직이 함수 포인터로 간접 호출되는 구조를 파악한 뒤, 기존 ordinal을 유지한 ezTransXP.dll을 제작해 Ollama와 연결했습니다.

사용하면서 개선한 부분

AI 결과를 캐시에 저장하고, 미완료 작업은 파일로 남겨 다음 실행에 재개하도록 개선했습니다. 숫자·기호와 이름만 있는 입력을 구분해 대사 번역을 우선하고, 문맥 설정과 실제 출력의 오류를 확인하며 조정했습니다.

  • C++ / Win32
  • Visual Studio
  • Ghidra
  • Ollama
  • 번역 캐시 · 작업 큐

기술 문제와 개선 내용
  • 호환 인터페이스 분석export 목록과 디컴파일 결과를 바탕으로 기존 플러그인의 진입점과 간접 호출 구조를 파악하고, 같은 ordinal을 가진 대체 DLL을 구성했습니다.
  • 번역 대기 시간과 중복 작업AI 번역 캐시를 분리하고 같은 원문의 중복 요청을 줄였습니다. 처리되지 않은 작업은 보존해 프로그램을 다시 실행했을 때 이어서 처리합니다.
  • 대사 중심 입력 분류숫자·기호, 인물·행성 이름처럼 문장 번역이 불필요한 입력을 구분합니다. 이름 목록의 정확 일치를 활용해 실제 대사를 제외할 가능성을 줄이는 방향으로 개선했습니다.
  • 문맥과 출력 품질게임 문맥과 관계 설정을 별도 파일로 관리하고, 글자 깨짐·프롬프트 노출·문장 잘림 등 실제 사용 중 발견한 오류를 점검했습니다.
  • 반복 개선에서 배운 점문장 연결과 호칭 보정 규칙을 추가한 뒤 새 번역의 품질 저하가 나타나, 기능 수보다 원문과 결과를 비교하는 검증이 중요하다는 점을 확인했습니다.

DLL은 Windows의 아랄트랜스 환경에서 사용하는 결과물입니다. 웹에서 실행하는 데모는 제공하지 않습니다.

수거함 신호등

의류수거함의 위치와 상태를 확인하고,
시민의 사진 제보를 관리와 민원 접수로 연결하는 서비스입니다.

웹 MVP 배포

시작한 문제

의류수거함 주변의 적치물이나 파손을 발견해도 관리 주체와 처리 상황을 알기 어렵습니다. 위치 정보와 시민의 관찰 기록을 연결해 어디에 있고, 어떤 상태인지 함께 확인하도록 기획했습니다.

서비스 설계

공공데이터의 수거함 위치를 기본 정보로 활용하고, 시민 제보를 그 위에 더하는 지도 경험을 설계했습니다. 제보가 없는 초기에도 수거함을 찾을 수 있고, 이후에는 변화한 상태를 기록하도록 구성했습니다.

구현한 사용자 흐름

Firebase 로그인과 데이터 저장을 연결하고, 사진·위치·상태를 포함한 제보를 등록하도록 구현했습니다. 자동 작성된 민원을 확인하면 서비스 운영자 접수함에 저장하고, 이용자는 접수 내역을 확인할 수 있습니다.

주요 기능과 설계 판단
  • 공공데이터와 시민 제보 결합등록된 수거함 위치를 기본 정보로 쓰고, 시민이 확인한 현장 상태를 함께 표시하도록 설계했습니다. 새 제보가 누적될수록 지도에 관리 맥락이 더해집니다.
  • 사진의 개인정보 처리사진에서 얼굴과 문자 영역을 자동으로 가리는 흐름을 추가했습니다. 검출 누락이나 과도한 가림에 대응할 수 있도록 저장 전 직접 확인과 추가 가리기를 제공합니다.
  • 저장과 접수 결과 구분사진 제보 저장과 운영자 접수 단계를 나누고, 접수가 실패했을 때 저장된 제보와 오류를 구별해 안내하도록 구성했습니다.
  • 시민과 운영자의 역할 구분시민은 본인의 제보와 접수 내역을 확인하고, 권한이 있는 운영자는 접수함에서 처리 기록을 관리하는 구조입니다.

현재 MVP의 자동 접수는 서비스 내부 접수입니다. 국민신문고 등 정부 기관으로의 실제 제출은 공식 사이트에서 완료해야 하며, 기관 자동 연계는 별도 확장 과제입니다.
